# ORIGIN — AFTERIMAGE

Электронная музыкальная студия на React, TypeScript, Vite и native Web Audio API. Светло-серый интерфейс, системный шрифт, автоматическая оригинальная мелодия без экранной клавиатуры.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес из терминала и нажмите «Слушать мелодию». Для production-сборки: `npm run build`. Также можно использовать pnpm с включённым lockfile.

## Музыка

Оригинальная тема в ре миноре: 108 BPM, 16 тактов, около 36 секунд. Вступление, диалог, кульминация и мягкое возвращение. Ритм колокольчиков чередуется между фразами.

Десять слоёв: колокольчики, BODY, GHOST, бас, стеклянные частицы, шумовой воздух, тёплый pad, деревянный pluck, механические щелчки и смычковое стекло. Последнее отвечает колокольчикам в среднем регистре: в отдельных тактах его фразы длятся около 3,6 секунды и пересекают тактовую черту. Pad связывает гармонии фразами на два такта; короткие акценты в этих местах редеют. Все звуки синтезируются в браузере, внешние аудиофайлы не требуются.

## Управление во время игры

- Темп, общая и индивидуальная громкость, выключение и solo основных синтов работают без перезапуска.
- Фильтр, резонанс, панорама и форма волны меняют активные ноты синтов; ADSR применяется к следующим нотам.
- Мягкость, металлический блеск и послезвучие меняют уже звенящие колокольчики.
- Плотность добавляет украшения во всех секциях; новая вариация меняет следующие ноты.
- Пространство и эхо управляют эффектами. Сброс возвращает исходные настройки без остановки.
- «Стоп» и Escape останавливают scheduler, голоса и эффекты.

AudioContext создаётся после действия пользователя. Планирование идёт по аудиочасам с горизонтом 100 мс; завершившиеся источники очищаются.

## Проверки

При работающем dev-сервере откройте:

- `/tests/audio.html` — основные синты, реальные сигналы, громкость, фильтр, огибающие и остановка.
- `/tests/new-voices.html` — pad, pluck, механические звуки, GHOST и смычковое стекло: сигнал, mute, STOP и cleanup.
- `/tests/live.html` — изменения активного звука и следующих нот без перезапуска.
- `/tests/arrangement.html` — тема и семь слоёв, включая смычковое стекло: непрерывность, тональность, динамика, запас уровня и cleanup.
- `/tests/layers.html` — бас и шум.
- `/tests/melody.html` — колокольчики и scheduler; нажмите Run audio checks.

Композиция оригинальная, не является нотной расшифровкой IAMX, Philip Glass или Erik Satie.
