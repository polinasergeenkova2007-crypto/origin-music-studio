# Музыкальный синтезатор — HTML / CSS / JavaScript

Готовая разметка находится в `index.html`, оформление — в `src/styles/global.css`, обработчики кнопок — в `src/app.js`. Аудиодвижок и композиция находятся в `src/audio`, `src/composition` и `src/state`. React и TypeScript не используются.

## Запуск без сборки

Из папки проекта запустите любой статический HTTP-сервер, например:

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:5173/ и нажмите ▶. Для ES-модулей нужен HTTP-сервер; открытие через file:// не поддерживается.

## Необязательная сборка

```sh
npm install
npm run dev
npm run build -- --base=/origin-music-studio/
```

Vite используется только как сервер разработки и инструмент сборки. Собранные файлы находятся в `dist`.

## Музыка и управление

Web Audio API синтезирует оригинальную композицию с коротким вступлением, двумя синтезаторами, колокольчиками, набатом, электропиано, басом, битом и дополнительными звуковыми слоями. Кнопки и регуляторы обновляют параметры во время воспроизведения; огибающие применяются к следующим нотам. Escape или ■ останавливает музыку.

HTML содержит доступные названия всех контролов, хотя видимый интерфейс показывает только цифры и значки.
